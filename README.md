# 🎉 Decoramor — Festas e Eventos

> Site institucional desenvolvido para apresentar os serviços, projetos e informações da **Decoramor — Festas e Eventos**, com foco em uma experiência visual elegante, moderna e responsiva.

---

## 📋 Sobre o projeto

O **Decoramor** é um projeto de desenvolvimento web criado para uma empresa especializada em decoração de festas e eventos.

O site foi desenvolvido com uma interface moderna e intuitiva, permitindo que os visitantes conheçam a empresa, visualizem trabalhos realizados, consultem os serviços disponíveis, deixem avaliações e encontrem a localização da empresa.

O projeto também conta com atalhos para contato através do **WhatsApp** e **Instagram**.

## ⭐ Avaliações

O site possui uma seção dedicada às avaliações dos clientes.

O visitante pode:

1. Informar seu nome;
2. Escrever um comentário sobre a experiência;
3. Selecionar uma nota;
4. Enviar sua avaliação.

As avaliações são apresentadas diretamente na página.

## 📍 Localização

A página possui uma integração com o **Google Maps**, permitindo que o visitante visualize a localização da empresa diretamente no site.

Também existe um botão para abrir a localização no Google Maps.
